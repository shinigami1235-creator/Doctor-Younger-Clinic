โหงวเฮ้ง : อุปนิสัยจากลักษณะใบหน้าแบ่งเป็น 7 ชนิด

จากที่เคยอธิบายพื้นที่ 3 ส่วนบนใบหน้าสามารถแบ่งหน้าได้ 7 ชนิด และสามารถทำให้รู้อุปนิสัยจากรูปหน้าทั้ง 7 ได้

A. ช่วงบน : ช่วงนี้ดูตั้งแต่อายุ 15 – 30 ปี พิจารณาวิถีชีวิตเบื้องต้นของการศึกษาและพืนฐานของครอบครัว

B. ช่วงกลาง : ช่วงนี้จะแทนอายุตั้งแต่ 31 – 50 ปี พิจารณาวิถีชีวิตเกี่ยวกับ ความ สำเร็จในหน้าที่การงาน การเงิน การมีชื่อเสียง และความสามารถในการดิ้นรนต่อสังคม

C. ช่วงล่าง : ช่วงนี้แทนถึงอายุตั้งแต่ 51 ปีขึ้นไปจนบั้นปลายชีวิต พิจารณาจากวิถีชีวิตเกี่ยวกับฐานะ ความมั่งคั่ง ความมั่นคง เรื่องบั้นปลายชีวิต และเรื่องที่อยู่อาศัย

ลักษณะใบหน้าทั้ง 7 ชนิด

1. ใบหน้ากลม : ส่วน B มีพื้นที่มากที่สุด ส่วน A และ C มีพื้นที่เท่าๆ กัน ใบหน้าเช่นนี้มักมีมนุษย์สัมพันธ์ดี เข้ากับคนอื่นง่ายแต่บางครั้งอาจเอาแต่ใจตนเอง และใจกว้างเกินไป ถ้าเป็นชายอาจจะเสียเงินมาก คิดจะคบกับคนใบหน้ากลม คุณต้องเป็นนักฟังที่ดี

2. ใบหน้ารูปไข่ : คล้ายๆ กับใบหน้ากลม แต่จะแคบกว่าเล็กน้อย เป็นคนละเอียด เป็นคนที่ทำอะไรรอบคอบ ไม่ผลีผลาม การตัดสินใจรวดเร็วและแม่นยำ เป็นคนน่าไว้ใจ บางครั้งอาจจะหยุมหยิมกับเรื่องเล็กๆ น้อยๆ เป็นคนค่อนข้างเข็มงวด เพื่อนจึงน้อย ใบหน้าเช่นนี้เป็นคนละเอียดรอบคอบ มีพลังสร้างสรรค์และอดทน ไม่ท้อถอย มั่นใจในตนเองสูงไม่ค่อยรับฟังความเห็นผู้อื่น

3. ใบหน้าสี่เหลี่ยม : พื้นที่ทั้ง 3 ส่วนบนใบหน้าเท่ากัน ทำให้ดูใบหน้าใหญ่ ใบหน้าเช่นนี้เวลาทำงานอะไรมักจะทุ่มเทสุดกำลัง มีปณิธานแรงกล้าไม่ย่อท้อต่ออุปสรรค เป็นคนซื่อสัตย์ ไม่ค่อยเปลี่ยนแปลงอะไรง่ายๆ มีความเห็นขัดแย้งกับผู้อื่น มีคุณสมบัติเป็นผู้นำที่ดีทีเดียว หากไว้ใจเขารับรองเขาจะสนับสนุนคุณเต็มที่

4. ใบหน้ายาว : ใบหน้าที่ดูแคบ แต่พื้นที่ทั้ง 3 ส่วนเท่าๆ กัน ปากเล็ก ใบหน้าเช่นนี้เป็นคนละเอียดถี่ถ้วน ชอบค้นคว้าวิจัย มีพรสวรรค์ และความสามารถในการทำงาน เดาใจยาก มีนิสัยชอบแสวงหาความรู้

5. ใบหน้ามาตรฐาน : พื้นที่ส่วน A และ B เท่ากันแต่พื้นที่ส่วน C น้อย ใบหน้าเช่นนี้เป็นคนชอบค้นคว้าไม่หยุดหย่อน มนุษยสัมพันธ์พอใช้ได้ เป็นคนที่ใครเห็นใครก็ชอบ ค่อนข้างเก็บตัว ถ้าเป็นชายมักเป็นคนรักเดียวใจเดียวไม่เปลี่ยนแปลง ผู้หญิงมักมีเพื่อนชายหลายคน เปิดเผยและกล้าหาญ

6. ใบหน้าผสม : พื้นที่ส่วน C มาก แต่พื้นที่ส่วน A กับ B ไม่เท่ากัน ใบหน้าเช่นนี้เป็นคนสนใจแต่เรื่องตัวเอง เป็นคนที่แสวงหาความรู้ไม่หยุด นิสัยเปิดเผย จริงใจ ชอบฟังคนยกยก เปลี่ยนใจง่าย

7. ใบหน้าสามเหลี่ยม : พื้นที่ส่วน A มาก แต่พื้นที่ส่วน B กับส่วน C ค่อนข้างน้อย ใบหน้าเช่นนี้รักความสะอาดเป็นชีวิตจิตใจ หากสิ่งใดไม่ได้ดังใจจะหงุดหงิดร้อนรน มีข้อเสียตรงที่เป็นคนลังเล ไม่เด็ดขาด เป็นคนที่หมกมุ่นกับสิ่งใดก็ทุ่มเทแรงกายแรงใจให้หมด มั่นใจตนเองมากไป มนุษยสัมพันธ์ไม่ค่อยดี
